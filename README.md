# DaySuite

DaySuite is a desktop app whose first app is **DayTex**, a LaTeX editor with a built-in compiler, templates, a writing mode for prose, and real-time collaboration with online projects.

Your projects stay in ordinary folders on your computer: no account, server or network is needed to create, edit, compile or export them. Signing in (accounts are by invitation) adds online projects, sharing and synced settings.

This repository only hosts the installers. The source code is private.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

- **Mac with Apple Silicon (M1 and later):** `DaySuite_<version>_aarch64.dmg`
- **Mac with an Intel processor:** `DaySuite_<version>_x64.dmg`
- **Windows:** the `.msi` or `-setup.exe` installer, when the release includes one

DaySuite checks this page for new versions (Home ▸ **Check for updates**).

## First launch

The installers aren't signed yet, so your system will warn you the first time:

- **macOS:** open the `.dmg` and drag DaySuite to Applications. Right-click DaySuite in Applications, choose **Open**, then **Open** again. On newer macOS versions, allow it under **System Settings ▸ Privacy & Security**.
- **Windows:** if SmartScreen appears, choose **More info ▸ Run anyway**.

## Help

Ask the person who invited you to DaySuite, or who runs your DaySuite server.
